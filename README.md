# AWS Solutions Architect Associate (SAA-C03) Learning Journey

## Overview

This repository documents my learning journey for the AWS Certified Solutions Architect – Associate (SAA-C03) certification.

The goal of this repository is to build a strong foundation in AWS Cloud, cloud architecture, security, networking, storage, monitoring, and infrastructure design through hands-on labs, notes, and practical exercises.

Rather than focusing only on certification preparation, this repository serves as a portfolio of my AWS learning and practical experience.

---

## Learning Objectives

* Understand AWS core services and architecture
* Learn cloud security best practices
* Gain hands-on experience with AWS services
* Prepare for the AWS Certified Solutions Architect Associate (SAA-C03) exam
* Build a foundation for Cloud Security and Security Engineering roles
